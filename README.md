# MVP - Sistema de Controle de Doações e Estoque
### Associação Comunitária Esperança Viva

Projeto desenvolvido para a disciplina de Projeto de Software (Experiência Prática III).

## 📌 Objetivo
Automatizar o controle de entrada e saída de doações recebidas pela Associação Comunitária Esperança Viva, garantindo rastreabilidade, controle de saldo e transparência na distribuição de mantimentos.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3.11
- **Testes Unitários:** Unittest
- **Integração Contínua (CI):** GitHub Actions
- **Controle de Versão:** Git / GitHub
